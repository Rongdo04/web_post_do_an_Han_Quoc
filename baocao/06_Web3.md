# 6. WEB3.JS

## 6.1. Giới thiệu Web3.js

### 6.1.1. Web3.js là gì?

Web3.js là một thư viện JavaScript cho phép tương tác với blockchain Ethereum từ ứng dụng JavaScript/Node.js. Nó cung cấp:

- **Kết nối với Blockchain**: Kết nối với Ethereum node (Ganache, Infura, etc.)
- **Quản lý Accounts**: Tạo, import, quản lý Ethereum accounts
- **Tương tác với Smart Contract**: Gọi functions, gửi transactions
- **Xử lý Transactions**: Gửi, theo dõi, verify transactions
- **Utilities**: Convert units, hash functions, etc.

### 6.1.2. Phiên bản

**Dự án sử dụng:** Web3.js v4.x

**Cài đặt:**
```bash
npm install web3
```

**Import:**
```javascript
import { Web3 } from "web3";
```

## 6.2. Vai trò của Web3.js trong dự án

### 6.2.1. Backend Integration

Web3.js đóng vai trò là **cầu nối** giữa backend Node.js và blockchain:

- **Kết nối với Ganache**: Kết nối backend với Ganache local network
- **Quản lý Backend Account**: Sử dụng private key để gửi transaction
- **Tương tác với Smart Contract**: Gọi contract functions từ backend
- **Xử lý Transactions**: Gửi transaction, đợi confirmation, lấy receipt

### 6.2.2. Service Layer

Web3.js được sử dụng trong `blockchainService.js` để:
- Khởi tạo kết nối blockchain
- Đăng ký hash công thức
- Xác minh hash công thức
- Cập nhật hash công thức

## 6.4. Khởi tạo kết nối

### 6.4.1. initializeBlockchain()

**Chức năng:** Khởi tạo kết nối Web3 và Smart Contract instance.

```javascript
async function initializeBlockchain() {
  try {
    // Kiểm tra cấu hình
    const validation = validateBlockchainConfig(false);
    if (!validation.isValid) {
      return { success: false, errors: validation.errors };
    }

    // Khởi tạo Web3 instance
    web3 = new Web3(blockchainConfig.ganacheUrl);

    // Kiểm tra kết nối
    const isConnected = await web3.eth.net.isListening();
    if (!isConnected) {
      throw new Error("Cannot connect to Ganache");
    }

    // Lấy account từ private key
    const account = web3.eth.accounts.privateKeyToAccount(
      blockchainConfig.privateKey
    );
    web3.eth.accounts.wallet.add(account);
    web3.eth.defaultAccount = account.address;

    // Khởi tạo contract instance
    if (blockchainConfig.contractAddress) {
      contract = new web3.eth.Contract(
        blockchainConfig.contractABI,
        blockchainConfig.contractAddress
      );
      contractInstance = contract;
    }

    return { success: true, account: account.address };
  } catch (error) {
    return { success: false, error: error.message };
  }
}
```

**Các bước:**

1. **Kiểm tra cấu hình:**
   ```javascript
   validateBlockchainConfig(false) // Không bắt buộc contract address
   ```

2. **Khởi tạo Web3:**
   ```javascript
   web3 = new Web3("http://127.0.0.1:7545");
   ```

3. **Kiểm tra kết nối:**
   ```javascript
   const isConnected = await web3.eth.net.isListening();
   ```

4. **Tạo account từ private key:**
   ```javascript
   const account = web3.eth.accounts.privateKeyToAccount(privateKey);
   web3.eth.accounts.wallet.add(account);
   web3.eth.defaultAccount = account.address;
   ```

5. **Tạo contract instance:**
   ```javascript
   contract = new web3.eth.Contract(ABI, contractAddress);
   ```

## 6.5. Đăng ký hash công thức

### 6.5.1. registerRecipeHash()

**Chức năng:** Đăng ký hash công thức lên blockchain.

```javascript
export async function registerRecipeHash(recipeHash, authorWalletAddress) {
  try {
    // Khởi tạo nếu chưa có
    if (!web3 || !contractInstance) {
      const initResult = await initializeBlockchain();
      if (!initResult.success) {
        throw new Error(`Blockchain initialization failed: ${initResult.error}`);
      }
    }

    // Validate inputs
    if (!recipeHash || typeof recipeHash !== "string") {
      throw new Error("Recipe hash is required and must be a string");
    }

    if (!authorWalletAddress || !web3.utils.isAddress(authorWalletAddress)) {
      throw new Error("Valid author wallet address is required");
    }

    // Gọi smart contract function
    const method = contractInstance.methods.registerRecipe(
      recipeHash,
      authorWalletAddress
    );

    // Estimate gas
    let gasEstimate;
    try {
      gasEstimate = await method.estimateGas({
        from: web3.eth.defaultAccount,
      });
    } catch (estimateError) {
      // Extract error message
      let errorMessage = estimateError.message || "";
      if (estimateError.cause?.message) {
        errorMessage = estimateError.cause.message;
      }
      throw new Error(errorMessage);
    }

    // Gửi transaction
    const tx = await method.send({
      from: web3.eth.defaultAccount,
      gas: gasEstimate,
      gasPrice: blockchainConfig.gasPrice,
    });

    // Đợi transaction được confirm
    const receipt = await web3.eth.getTransactionReceipt(tx.transactionHash);

    if (!receipt || !receipt.status) {
      throw new Error("Transaction failed or was reverted");
    }

    return {
      success: true,
      transactionHash: tx.transactionHash,
      blockNumber: Number(receipt.blockNumber), // Convert BigInt to Number
      timestamp: new Date(),
      gasUsed: receipt.gasUsed.toString(),
    };
  } catch (error) {
    // Extract error message
    let errorMessage = error.message || "";
    if (error.cause?.message) {
      errorMessage = error.cause.message;
    }

    return {
      success: false,
      error: errorMessage,
    };
  }
}
```

### 6.5.2. Các bước chi tiết

1. **Khởi tạo (nếu cần):**
   ```javascript
   if (!web3 || !contractInstance) {
     await initializeBlockchain();
   }
   ```

2. **Validate inputs:**
   ```javascript
   if (!recipeHash || typeof recipeHash !== "string") {
     throw new Error("Recipe hash is required");
   }
   if (!web3.utils.isAddress(authorWalletAddress)) {
     throw new Error("Invalid wallet address");
   }
   ```

3. **Tạo method:**
   ```javascript
   const method = contractInstance.methods.registerRecipe(
     recipeHash,
     authorWalletAddress
   );
   ```

4. **Estimate gas:**
   ```javascript
   const gasEstimate = await method.estimateGas({
     from: web3.eth.defaultAccount,
   });
   ```
   - Nếu estimate fail → transaction sẽ revert
   - Extract error message từ `error.cause.message` (Web3 v4)

5. **Gửi transaction:**
   ```javascript
   const tx = await method.send({
     from: web3.eth.defaultAccount,
     gas: gasEstimate,
     gasPrice: blockchainConfig.gasPrice,
   });
   ```

6. **Đợi confirmation:**
   ```javascript
   const receipt = await web3.eth.getTransactionReceipt(tx.transactionHash);
   ```

7. **Xử lý kết quả:**
   ```javascript
   return {
     success: true,
     transactionHash: tx.transactionHash,
     blockNumber: Number(receipt.blockNumber), // Convert BigInt
     timestamp: new Date(),
   };
   ```

### 6.5.3. Xử lý lỗi

**Extract error message:**
```javascript
let errorMessage = error.message || "";

// Web3 v4: error message trong error.cause.message
if (error.cause?.message) {
  errorMessage = error.cause.message;
} else if (error.reason) {
  errorMessage = error.reason;
} else if (error.data?.message) {
  errorMessage = error.data.message;
}
```

**Ví dụ error messages:**
- `"Recipe hash already registered"` → Hash đã tồn tại
- `"Hash cannot be empty"` → Hash rỗng
- `"Author address cannot be zero"` → Author address không hợp lệ

## 6.6. Xác minh hash công thức

### 6.6.1. verifyRecipeHash()

**Chức năng:** Xác minh hash công thức có tồn tại trên blockchain không.

```javascript
export async function verifyRecipeHash(recipeHash) {
  try {
    // Khởi tạo nếu chưa có
    if (!web3 || !contractInstance) {
      const initResult = await initializeBlockchain();
      if (!initResult.success) {
        return {
          success: false,
          error: initResult.error,
          exists: false,
        };
      }
    }

    if (!recipeHash || typeof recipeHash !== "string") {
      return {
        success: false,
        error: "Recipe hash is required",
        exists: false,
      };
    }

    // Gọi view function (không tốn gas)
    const result = await contractInstance.methods
      .verifyRecipe(recipeHash)
      .call();

    return {
      success: true,
      exists: result.exists,
      author: result.author,
      timestamp: result.timestamp
        ? new Date(Number(result.timestamp) * 1000)
        : null,
      blockTimestamp: result.timestamp,
    };
  } catch (error) {
    return {
      success: false,
      error: error.message,
      exists: false,
    };
  }
}
```

### 6.6.2. Đặc điểm

- **View function**: Không thay đổi state, không tốn gas
- **Gọi bằng `.call()`**: Không gửi transaction
- **Trả về ngay lập tức**: Không cần đợi confirmation

### 6.6.3. Kết quả

```javascript
{
  success: true,
  exists: true,  // Hash đã được đăng ký
  author: "0x1D7107c7ac42fdb28b10aa3badc08020248dce16",
  timestamp: Date,  // JavaScript Date object
  blockTimestamp: "1702051200"  // Unix timestamp (string)
}
```

## 6.7. Cập nhật hash công thức

### 6.7.1. updateRecipeHash()

**Chức năng:** Cập nhật công thức (tạo version mới với hash mới).

```javascript
export async function updateRecipeHash(oldHash, newHash, authorWalletAddress) {
  try {
    // Khởi tạo nếu chưa có
    if (!web3 || !contractInstance) {
      await initializeBlockchain();
    }

    // Validate inputs
    if (!oldHash || !newHash) {
      throw new Error("Both old and new hash are required");
    }

    if (!web3.utils.isAddress(authorWalletAddress)) {
      throw new Error("Valid author wallet address is required");
    }

    // Gọi smart contract function
    const method = contractInstance.methods.updateRecipe(
      oldHash,
      newHash,
      authorWalletAddress
    );

    // Estimate gas
    const gasEstimate = await method.estimateGas({
      from: web3.eth.defaultAccount,
    });

    // Gửi transaction
    const tx = await method.send({
      from: web3.eth.defaultAccount,
      gas: gasEstimate,
    });

    // Đợi confirmation
    const receipt = await web3.eth.getTransactionReceipt(tx.transactionHash);

    return {
      success: true,
      transactionHash: tx.transactionHash,
      blockNumber: Number(receipt.blockNumber),
      timestamp: new Date(),
    };
  } catch (error) {
    return {
      success: false,
      error: error.message,
    };
  }
}
```

## 6.9. Xử lý BigInt

### 6.9.1. Vấn đề

Web3.js v4 trả về `blockNumber` dưới dạng `BigInt`, nhưng MongoDB schema yêu cầu `Number`.

### 6.9.2. Giải pháp

```javascript
// Convert BigInt to Number
blockNumber: Number(receipt.blockNumber)
```

**Lưu ý:**
- Chỉ convert khi giá trị nhỏ (blockNumber thường < 2^53)
- Nếu giá trị lớn, cần xử lý khác (lưu dạng string)

## 6.10. Error Handling

### 6.10.1. Web3 v4 Error Format

```javascript
try {
  await method.estimateGas();
} catch (error) {
  // Error message có thể ở nhiều nơi:
  // 1. error.cause.message (phổ biến nhất)
  // 2. error.reason
  // 3. error.data.message
  // 4. error.message
  
  let errorMessage = error.message || "";
  if (error.cause?.message) {
    errorMessage = error.cause.message; // Ưu tiên
  }
}
```

### 6.10.2. Common Errors

| Error | Nguyên nhân | Giải pháp |
|-------|-------------|-----------|
| `"Cannot connect to Ganache"` | Ganache chưa chạy | Khởi động Ganache |
| `"Recipe hash already registered"` | Hash đã tồn tại | Kiểm tra hash trước |
| `"Gas estimation failed"` | Transaction sẽ revert | Kiểm tra contract logic |
| `"Contract instance not initialized"` | Contract chưa deploy | Deploy contract và set address |

## 6.12. Kết luận

Web3.js là công cụ không thể thiếu để tương tác với blockchain từ backend. Trong dự án này, nó đóng vai trò:

- Kết nối backend với Ganache
- Quản lý backend account (private key)
- Gọi Smart Contract functions
- Xử lý transactions và errors
- Convert dữ liệu (BigInt → Number)

Nhờ Web3.js, backend có thể tích hợp blockchain một cách mượt mà và xử lý các edge cases một cách chính xác.
